# The AppImage catalog feed

Everything AppGarden shows comes from one file:

    https://appimage.github.io/feed.json

It is generated by the site at https://github.com/AppImage/appimage.github.io
from the `data/` and `database/` directories of that repository. The project
README says the output format "is not finalized yet and is subject to change
any time without prior notice", so the parser must be strict about what it
requires and lenient about what it ignores (unknown keys are skipped, missing
optional keys become nil, but a top-level document that is not an object with
an `items` array is an error that is shown to the user).

The facts below were measured against the live feed on 2026-09-27. The
counts change; the shapes are what matters.

## Top level

    {
      "version": 1,
      "home_page_url": "https://appimage.github.io/",
      "feed_url": "https://appimage.github.io/feed.json",
      "description": "AppImage applications for Linux without installation",
      "icon": "https://appimage.github.io/apple-touch-icon.png",
      "favicon": "https://appimage.github.io/favicon.ico",
      "expired": false,
      "items": [ ... ]
    }

Size: about 930 KB, 1551 items. The whole document is downloaded in one
request; there is no paging and no per-item endpoint.

## An item

Every item has exactly these keys (the first eight always, the last three
only on about 20 percent of the items):

| Key | Type | Nullable | Notes |
| --- | --- | --- | --- |
| `name` | string | no | Unique. The catalog identifier. Underscores stand for spaces (`Apache_NetBeans`, `APK_Editor_Studio`). Never contains `/` or spaces. |
| `description` | string | yes (12 percent null) | One line up to a few paragraphs, plain text, up to about 2600 characters. |
| `categories` | array of string | array never null, but elements can be `null` | freedesktop menu categories, mostly one entry. Seen: Utility, Development, Network, Office, Graphics, AudioVideo, Game, Qt, Science, System, Education, Finance, Audio, Application, Chat, GNOME, Video, GTK, Settings, Music, Engineering, TerminalEmulator, Astronomy, Emulator, VideoConference, News, HamRadio, Electronics, WordProcessor and a `null` on 14 items. |
| `authors` | array of `{name, url}` | yes (21 percent null) | Usually one GitHub user. `url` is a full https URL. |
| `license` | string | yes (50 percent null) | SPDX-ish. Seen: `MIT`, `GPL-3.0`, `GPL-3.0-or-later`, `GPL-3.0+`, `GPL-2.0+`, `Apache-2.0`, `LGPL-3.0`, `AGPL-3.0`, `MPL-2.0`, `NOASSERTION`, `LicenseRef-proprietary`, and `LicenseRef-proprietary=https://...LICENSE` (an `=` followed by a URL to the license text). |
| `links` | array of `{type, url}` | yes (21 percent null) | See "Links" below. |
| `icons` | array of string | yes (14 percent null) | Relative paths, see "Assets". Never more than one element. Formats seen: png (1104), svg (226), svgz (5), a bare file named `DirIcon` (2). |
| `screenshots` | array of string | yes (2 percent null) | Relative paths, never more than one element, always png so far. |
| `libc` | string | only present on some items | `"host"` seen. |
| `self_contained` | bool | only present on some items | |
| `glibc_required` | string | only present on some items | e.g. `"2.30"`. |

Example with everything present:

    {
      "name": "4KWALL",
      "description": "Browse, download, and auto-change 4K wallpapers",
      "categories": ["Graphics"],
      "authors": [{"name": "rishabh3354", "url": "https://github.com/rishabh3354"}],
      "license": "LicenseRef-proprietary=https://raw.githubusercontent.com/rishabh3354/4KWALL/main/share/license/LICENSE",
      "links": [
        {"type": "GitHub", "url": "rishabh3354/4KWALL"},
        {"type": "Download", "url": "https://github.com/rishabh3354/4KWALL/releases"}
      ],
      "icons": ["4KWALL/icons/512x512/com.warlordsoftwares.wallpaper-app-4kwall.png"],
      "screenshots": ["4KWALL/screenshot.png"]
    }

## Links

`links[].type` takes three values:

| type | count | `url` shape |
| --- | --- | --- |
| `GitHub` | 1210 | `owner/repo`, NOT a URL. Prefix `https://github.com/` to open it. |
| `Download` | 1220 | 1210 times `https://github.com/<owner>/<repo>/releases` (a web page, not a file). 15 times an openSUSE Build Service mirror list such as `https://download.opensuse.org/repositories/home:/pbek:/QOwnNotes/AppImage/QOwnNotes-latest-x86_64.AppImage.mirrorlist`. Once a foreign download page (`https://bitbucket.org/kfj/pv/downloads`). |
| `Install` | 6 | Same shape as `Download`; older synonym. Treat identically. |

An item can have `links: null` (326 items), a `GitHub` link only, a
`Download` link only (15 items, the openSUSE ones), or both.

There is no direct AppImage file URL in the feed. The download target is
resolved at install time, see INSTRUCTIONS.md section 8, "Resolving the
download and installing". That resolution is a transliteration of the site's
own `code/find-appimage.sh`, deliberately, so that "the AppImage of this
release" means the same thing in the app as on the website.

## Assets

Relative paths in `icons` and `screenshots` resolve against
`https://appimage.github.io/database/`:

    https://appimage.github.io/database/4KWALL/icons/512x512/com.warlordsoftwares.wallpaper-app-4kwall.png
    https://appimage.github.io/database/4KWALL/screenshot.png

Both verified to return HTTP 200 with `image/png`. The same files are also
served from
`https://raw.githubusercontent.com/AppImage/appimage.github.io/master/database/...`
but AppGarden uses only the first form: GitHub Pages serves it without a
rate limit, while `raw.githubusercontent.com` throttles bursts of requests
(a grid of 40 visible icons is such a burst) and `api.github.com` allows
only 60 anonymous requests per hour. Every asset and every piece of text
AppGarden shows while browsing comes from `https://appimage.github.io/`.

Icon sizes in the path vary: `512x512`, `256x256`, `128x128`, `100x100`,
`48x48`, `scalable` (svg). AppGarden displays icons at 64 and 128 points, so
anything from 48 px up is usable; 48 px icons will look soft at 128 points,
which is acceptable.

SVG and svgz icons (15 percent) cannot be decoded by NSImage in this stack.
AppGarden treats them like a missing icon and draws its generic application
icon placeholder. Do not try to rasterize SVG with an external tool.

The per-application web page is `https://appimage.github.io/<name>/`
(verified 200). AppGarden links to it as "View on appimage.github.io" on the
detail page.

## Update frequency and caching

The feed is regenerated by the site's CI several times a day. It is served by
GitHub Pages with `ETag` and `Last-Modified` headers, so a conditional request
(`curl -z <cached-file>` or `-H 'If-None-Match: ...'`) returns 304 when
nothing changed. AppGarden refreshes at most once per launch and on explicit
reload, see INSTRUCTIONS.md section "Catalog cache".
